# Java Swing Calculator 🖩

A simple calculator application built using **Java Swing**. It provides a graphical user interface (GUI) with buttons for numbers and basic arithmetic operations.

## ✨ Features

* **Basic Arithmetic:** Addition (+), Subtraction (-), Multiplication (*), and Division (/).
* **Decimal Support:** Perform calculations with decimal numbers.
* **Clear Button:** Reset the calculator using the `C` button.
* **Interactive GUI:** User-friendly interface built with Java Swing.
* **Event Handling:** Uses Java's `ActionListener` to handle button clicks.

## 🛠️ Technologies Used

* **Java** — Programming language.
* **Java Swing** — GUI components such as buttons, panels, and text fields.
* **AWT Event Handling** — Handles user interactions with the calculator.

## 📋 Prerequisites

Before running this project, ensure you have:

* Java Development Kit (JDK) installed.
* A code editor such as Visual Studio Code or IntelliJ IDEA.

## 🧮 Available Operations

| Button | Function             |
| ------ | -------------------- |
| `0–9`  | Enter numbers        |
| `+`    | Addition             |
| `-`    | Subtraction          |
| `*`    | Multiplication       |
| `/`    | Division             |
| `.`    | Enter decimal values |
| `=`    | Calculate the result |
| `C`    | Clear the calculator |
